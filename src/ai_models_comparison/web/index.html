AI models comparison

New open-weights models, judged against the memory of your machine.

How to use this page
  1. Describe your machine. Choose a preset or type the GPU memory and the system memory. On a Mac with Apple silicon, tick one shared pool. The list is judged again as you type.
  2. Read the verdicts. Click a model to see every build, where each fits, and the command to download and run the best one.
  3. Compare. Tick two to four models to see them side by side. The page address keeps your machine and your choice: copy it to share.
